# Quantumult X 去开屏重写（按 App 拆分）

以墨鱼 [StartUpAds.conf](https://ddgksf2013.top/rewrite/StartUpAds.conf)（2026-08-29）为基础，按 App 拆成独立重写，
每个文件只含该 App 自己的规则和它实际用到的 MITM 主机——只订阅自己装了的 App，MITM 面最小。

其中部分 App 在 [可莉](https://hub.kelee.one) / [Loon Lab](https://loonlab.103516.xyz/Plugin/) 插件里有更全的去广告规则，已转换为 QX 写法后合入（只收去广告行：开屏、信息流、弹窗、广告 SDK、埋点；不收净化、功能增强、解锁、重定向）。

## 安装

在 iPhone 上点表格里的「安装」，会跳转 Quantumult X 并添加为重写资源（[官方 URL Scheme](https://github.com/crossutility/Quantumult-X/blob/master/url-scheme.md)）。若点了打开的是浏览器而不是 QX，说明本机 QX 通用链接未激活，可复制「文件」列的 raw 地址手动添加到 `[rewrite_remote]`。

安装后需在 QX 中开启 MitM 并信任证书；hostname 已写在各文件末尾，会自动并入。安装链接已设 `update-interval=2592000`（30 天自动更新一次）。

## 说明

- 「更新」列标注了合入的插件来源：**追加** = 保留墨鱼原规则并追加插件规则；**替换** = 墨鱼原规则已被覆盖或已失效，改用插件规则。
- 少数脚本托管在 kelee.one，若 QX 日志显示脚本拉取失败，该条规则不生效，其余规则不受影响。
